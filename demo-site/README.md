# Demo Site

This is a dependency-free HTML, CSS, and JavaScript test fixture for `design-intent-to-frontend`.

Open `index.html` directly in a browser. No package manager, build step, framework, or local server is required.

## Intentional Test Issues

The page should remain usable, but it intentionally keeps a few mild visual issues for later Skill tests:

- Desktop title is slightly too centered vertically for some reference layouts.
- Body text block is a little wide.
- Image and text layout is somewhat template-like.
- Mobile spacing between the call-to-action and visual area is slightly loose.

Do not fix these issues during repository initialization. They are future test inputs.

## Baseline Requirements

- Page opens directly from the file system.
- No serious functional errors.
- No horizontal scrolling at common mobile widths.
- Basic semantic HTML is present.
- CSS is intentionally simple and easy to inspect.
